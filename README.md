# pharmacy-management-system

A desktop-based Pharmacy Management System developed using Python, Tkinter, and MySQL. The project helps manage medicine records, stock, barcode identification, and pharmacy operations through a user-friendly interface.

Key Features

- 🔐 Login & Logout System
- 💊 Add, View, Search & Update Medicines
- 📦 Medicine Stock Management
- 📅 Expiry Date Management
- 🔖 Barcode Generation & Identification
- 🗄️ MySQL Database Integration
- 🖥️ Tkinter-based Desktop GUI

Technologies Used

- Python 3.11
- Tkinter
- MySQL
- mysql-connector-python
- Pillow
- Barcode

How to Run

pip install mysql-connector-python pillow python-barcode
python gui.py
